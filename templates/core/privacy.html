Aviso de privacidade do protótipo

Este aviso descreve como os dados serão tratados durante o desenvolvimento acadêmico do VivaBem.

Dados do cadastro

Nesta etapa são armazenados nome, e-mail, senha protegida, perfil de acesso e data de aceite deste aviso.

Finalidade

Os dados são usados para identificar a conta, controlar o acesso e permitir os recursos correspondentes a cada perfil.

Compartilhamento e controle

Informações de pessoas idosas não serão liberadas automaticamente a familiares ou profissionais. Os vínculos e permissões dependerão de autorização registrada no sistema.

Limites do protótipo

O VivaBem é um projeto acadêmico em desenvolvimento. Ele não substitui serviços ou profissionais de saúde e não deve ser utilizado para emergências.
